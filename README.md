
# AI-Based Predictive Maintenance System

## Project Overview
This project uses Machine Learning to predict
potential machine failures using sensor data.

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
Random Forest Classifier

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Categorical Encoding
7. Model Training
8. Model Evaluation
9. Failure Prediction

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## Project Objective
To identify potential machine failures
before they occur using machine sensor data.
